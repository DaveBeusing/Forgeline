# Predictive traffic — active finalization

The planner now computes a complete immutable-input batch in canonical full-identity order. It predicts sixteen acceleration/braking/yaw-limited intervals over a configured 0.25–10 second horizon, checks swept relative separation instead of only endpoints, and gives waiting age priority over identity. Physical geometry and existing reservations retain a mandatory veto. Shared work exhaustion makes the entire batch unavailable without committing partial history. There are at most 512 participants and 128 passage leases. The compatibility single-vehicle API refuses multi-vehicle frames; repeated calls cannot select winners by call order.

Copied directed passage envelopes establish exclusive admission. Waiting age arbitrates opposing directions; an admitted owner retains priority through entry and until its entire oriented footprint clears. A changed/canceled order or a wreck cannot release physical occupancy. An unentered, unchanged approach expires after 80 ticks. Complete physical coverage is required before release. Checkpoint revision 3 stores sorted detached participant, wait-for, reverse-target and passage-lease records and validates the complete replacement before applying it.

A bounded wait-for graph admits at most one feasible stopped-vehicle reverse escape per cycle. The entire reverse route is swept and existing reservations/passage ownership remain vetoes. This is an advisory target: the movement owner must brake, bound reverse acceleration, sweep each actual step, revalidate the binding and preserve the original order. A fully blocked rear produces no escape. Multiple vehicles already inside a passage form a wait cycle rather than receiving conflicting admissions.

Twenty local regression cases pass through copied-neighborhood and selected-route prediction integration, including crossing/input order, shared work exhaustion, stale/reused identities, geometry veto, checkpoint parity, safe/blocked reverse escape, command changes, rear clearance and a dead owner that still physically blocks. The compatibility API also rejects repeated single calls on a multi-participant frame.

Pinned-grid narrow-lane discovery and retained predicted-intersection priority are now implemented and tested. Traffic contract revision 2 copies per-vehicle collision neighborhoods and retains complete-world occupancy for lease release. Selected-route prediction follows subsequent waypoints and samples the authoritative terrain height, rather than stopping at the first local target. Real legacy search IDs and start rotations survive route publication; authoritative schema 9 explicitly declares this changed state.
