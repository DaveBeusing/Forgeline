## Render/input snapshot coherence

The render owner can receive a newer completed snapshot than the input owner. Group capability facts are therefore presented as current only when their copied tick and canonical selected-identity set match the rendered snapshot. Otherwise group controls show Updating and remain disabled until the matching context arrives. Tactical item counts come from the same rendered action snapshot, and mismatched selection sets cannot expose active item controls. The published slot records retain enabled state: pressing a disabled item cannot become an activation merely because capabilities become available before release. A legitimately enabled action is still revalidated by the existing adapter/authoritative command path on release/tick. No tick equality is imposed across an otherwise valid held gesture.
