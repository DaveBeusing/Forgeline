# Production surface masters

The physical material set has twenty-four native 4096 x 4096 lossless PNG
masters: Base Color, tangent Normal and packed ORM for the shared sixteen-cell
Directorate/world atlas and seven terrain families. These are independently
authored periodic surfaces, not enlarged versions of the historical sources.
`build/Author-ProductionSurfaces.py` reproduces them with numpy and Pillow.
All randomness has fixed seeds. Historical sources remain editable references.

## Shared object surfaces

The atlas preserves the existing four-by-four UV identities: painted armor,
structural steel, rubber, canvas; glass, warnings, concrete, heat-treated steel;
worn armor, vents, wood, mineral rock; conifer, scrub, grass, service panels.
Metal panels include recessed joints and flush fasteners. Canvas has woven
relief; rubber has recessed tread; wood has grain and board joints; foliage
uses botanical stems, needles, leaves and blades. Height and wear fields drive
the corresponding normal, ambient occlusion and roughness data. Dielectrics
have zero metallic response; sensor glass is smooth, dark and nonmetallic.
Paint exposes metal only at authored worn regions. Base Color has no lighting
or cast shadows baked into it.

All object materials that use the atlas now use its matching atlas Normal.
The compiler derives BC7 textures at 2048 Base Color, 1024 Normal and 512 ORM.
Terminal atlas mips remain 128 x 128, or 32 texels per cell. Existing UV insets
protect adjacent cells. Runtime limits are explicit, not inferred from source
dimensions. The texture chains occupy 5,586,944 + 1,392,640 + 344,064 =
7,323,648 bytes. This is a texture allocation budget, not total GPU memory.

Production BC7 sources explicitly choose `textureCompressionQuality: balanced`.
The historical textures retain the default `best`. Large detailed normal maps
made clean best-quality encoding prohibitively slow for routine authoring
validation. Both settings preserve format, channel semantics and resident size.
The compiler validates the setting, includes it in cache identity and keeps
encoding single-threaded and deterministic. The normal-direction regression
uses a varying tangent field, a six-degree maximum decoded error, repeat-build
equality and quality-change cache invalidation. This numeric tolerance is not
a substitute for visual review of the authored surfaces.

`build/Refine-ProductionMeshes.py` authors small manufactured edge bevels
while preserving outer bounds, component UV orientation, pivots and stable
asset IDs. Unit LOD0, articulated tank turret, building LOD0 and supported prop
sources get sibling `_production.gltf` sources. Original source meshes remain
available. Existing LOD1/LOD2 and collision sources are unchanged; normal
gameplay retains their deliberately inexpensive role silhouettes. The
extractor's non-box topology remains intact. Bevels are 3.5% of the smallest
component extent. Tangents are generated by the existing importer.

Run `build/Author-UnitRunningGear.py` after the bevel pass to author faceted
wheels, tracked belts with visible road wheels and hollow weapon barrels in
the existing rubber/hot-metal component regions. The six unit families and
articulated turret retain original bounds and socket positions. This pass
requires freshly bevelled input; the prescribed authoring order is explicit.

## Terrain

Seven complete material families cover dry dirt, cracked earth/mud, rocky
scrub/grass, ash/industrial ground, concrete, bedrock and crushed gravel.
Bedrock and gravel have independent aggregate scale and fissure fields.
Periodic macro variation, aggregate and microdetail use the same physical
fields across maps. Concrete has joints and pore relief; mud has shrinkage
cracks. Scorched ground uses a darker ash material factor. These surfaces do
not encode gameplay identities solely in roughness.

Each terrain Base Color remains RGBA8 at 1024 because the CPU terrain profile
also samples it. Each Normal/ORM is BC7 at 512 with a full semantic mip chain.
Resident budget is 44,040,556 bytes for seven complete sets. Terrain normal
Y follows the existing tangent-space convention; normals are renormalized
during runtime-size and mip generation. The existing terrain macro splatting
and layer selection continue to apply. Control maps remain lossless data.

Production terrain covers 24–32 metres per tile: 32–42.7 runtime Base Color
texels per metre, 128–170.7 source texels per metre. This replaces the old
80–160 metre coverage without raising texture memory; macro layer blending
still operates at world scale. The shared atlas
has 512 runtime Base Color texels per cell; density on individual components
depends on their established UV layout and world scale. No uniform density
claim is made for the whole object set. Runtime caps require camera review
before raising them, especially for strategic views.

## Qualification

`build/Author-IndustrialProps.py` follows the bevel authoring pass and replaces
seven prop sources with functional detail: ribbed closed drums, hollow flanged
pipes, slatted pallets with feet, fences with posts and rails, pole-mounted
industrial lamps, faceted mineral rocks and clustered rubble. It retains each
original outer bound and UV/material cell convention. Their inexpensive
reduced LOD meshes remain available for normal/strategic views.

The source catalog contains 341 stable assets. Asset compilation and runtime
qualification must pass before client review. The production master test
checks native dimensions, semantic color spaces, explicit caps and mip policy;
existing material completeness tests verify all physical mesh dependencies
and LOD material identities. Mesh authoring asserts unchanged outer bounds.

Use the reference qualification matrix in
[RTS visual qualification](RtsVisualReferenceQualification.md). Data checks do
not establish visual acceptance: screenshots, terrain/foliage aliasing and
LOD-transition review, exact 4K output and controlled performance/total-VRAM
qualification remain separate acceptance work. No 60 FPS guarantee follows
from the texture budget. Roads/bridges keep their current production geometry;
this change does not add animation, skeletons, unique wreck models or LOD3.
