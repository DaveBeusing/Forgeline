# Runtime content notices

The Directorate material sources are repository-authored procedural patterns;
their authoring README reports no external imagery, texture data, fonts or
licensed source material. The decal and VFX atlases are documented as original
repository authoring content. Command-core kit metadata describes original
repository geometry with no third-party inputs or separate external license grant.

This notice records the existing source descriptions. It grants no additional
rights and does not create a repository license. Any repository LICENSE or NOTICE
file is copied alongside this notice when present. Future externally licensed
content must add its required attribution and redistribution terms here before
being packaged.

BCnEncoder.Net 2.3.0 (MIT/Unlicense) is used only by the offline asset compiler.
Neither that compiler nor its authoring dependency is part of the player package.
The player package retains its required application runtime dependencies.

Bundled UI text uses unmodified DejaVu Sans Regular/Bold (font version 2.35).
Bitstream Vera and Arev redistribution notices are shipped in
`ThirdPartyNotices/DejaVuFonts.txt`. Source revisions and SHA-256 hashes are
recorded in `assets/source/ui/fonts/README.md` and `metrics.json`. Only the
precompiled atlas/metrics are needed by the player; source TTF files and
font-authoring libraries are excluded from the package.

The optional Directorate menu still is a repository-authored native render of the existing
Directorate/Central Divide models and materials. No external imagery was introduced.
Composition/export details and the source hash are recorded in
`assets/source/branding/forgeline/menu/README.md`; this notice grants no additional rights.
